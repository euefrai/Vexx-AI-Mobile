# Research benchmark datasets

## Frozen dataset v1.0.0

`benchmarks/research_quality_v1.json` is a small, versioned fixture dataset.
Its SHA-256 is
`e29379d7b805d25a3a5bea69ab3f9ea11f101cec13cc86c30fa44c221a4d489b`.
Tests pin this digest so edits require an explicit dataset-version update.

The corpus contains 11 locally authored fictional records and eight query
cases (nine retrieval queries): factual QA, multi-hop, conflict evidence,
source attribution/republication, HTML/CSV document retrieval, numeric rows,
temporal revisions, and adversarial instruction-like text. Separate 10-, 25-,
and 50-step checkpoint scenarios exercise persistence and restoration.

These fictional records are controlled retrieval fixtures, **not verified
real-world facts** and not a score of factual answering. The benchmark cannot
establish that external sources are true. It measures the retrieval pipeline
against the labels attached to these known local records.

## Annotation requirements

Every query lists document IDs and graded relevance. A grade is a fixture
annotation for retrieval ordering only. Unknown IDs, invalid grades,
duplicate case/document IDs, unsupported categories, malformed queries, and
non-fixture truth bases are rejected by the loader.

Future factual-answer datasets must have independently reviewed references,
expected passages, temporal scope, contradictory evidence, and an explicit
annotation source. Outputs generated by Júlia must not be reused as the gold
answer. No such real-world factual dataset ships in this version.

## Reproducibility and online tests

The runner indexes fixture originals into an isolated temporary directory and
SQLite database. It reports the exact dataset digest and runtime versions.
Network search is not used. Any future live-provider evaluation must be a
separate test class with recorded query time, provider, retrieval timestamp,
and raw-source hashes; changing web results must not mutate this frozen
dataset.
