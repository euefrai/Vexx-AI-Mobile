# Segurança — Vexx AI

## Versões suportadas

A versão mais recente da branch `main` é a única que recebe correções de
segurança. Versões antigas podem não ser atualizadas.

## Como relatar uma vulnerabilidade

1. Abra um issue em
   [github.com/euefrai/Vexx-AI-Mobile/issues](https://github.com/euefrai/Vexx-AI-Mobile/issues)
   com o rótulo `security`.
2. Descreva o impacto e os passos mínimos para reproduzir.
3. **Não inclua** senhas, chaves de API, tokens do agente, dados pessoais ou
   detalhes que permitam explorar terceiros.
4. Se o relato for sensível, peça no issue um canal privado antes de enviar os
   detalhes.

Não há programa de recompensas financeiras nem SLA de resposta. O projeto é
independente.

## Escopo

- Aplicativo web em `https://vexx-ai.space`
- Relay FastAPI (`server.py`)
- Agente local do Windows (`pc_agent.py`, `agent_runtime.py`, `remote_access.py`)

Provedores de IA, buscadores, lojas e serviços de hospedagem têm programas e
políticas próprios.

## Pesquisa de boa-fé

Pesquisas de segurança de boa-fé são bem-vindas. Ao testar:

- use apenas contas e aparelhos que você controla;
- não acesse dados de terceiros;
- não degrade o serviço, não apague dados e não faça engenharia social;
- pare assim que confirmar o problema e relate de forma responsável.
