Use uma API ou um modelo que roda no seu computador.
A chave fica neste usuário do Windows, protegida pelo sistema. Somente as mensagens enviadas ao Copiloto vão para o provedor escolhido; nenhum conteúdo ou índice de arquivos é enviado automaticamente. Ao trocar provedor ou endereço, informe novamente a chave.
Ollama, Hermes e outros modelos locais
Inicie o serviço antes de testar. Ollama usa normalmente http://127.0.0.1:11434. Para Hermes, LM Studio, llama.cpp e proxies, informe o endereço base da API compatível com OpenAI (geralmente termina em /v1), a porta real e o modelo publicado pelo serviço. Este aplicativo não inicia nem instala esses serviços.
