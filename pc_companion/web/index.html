Como o Vexx PC inicia projetos

Python usa um ambiente .vexx-venv do projeto. Node/Vite usa o npm instalado. Interfaces HTML são servidas por HTTP local, com CSS e JS. Um manifesto vexx-project.json pode declarar serviços em ordem para projetos que precisam de outra configuração.
