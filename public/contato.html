Contato

Fale com o projeto.

O canal público oficial é o GitHub Issues. Ele mantém o histórico verificável, permite acompanhar a resposta e evita pedidos duplicados.

GitHub Issues

github.com/euefrai/Vexx-AI-Mobile/issues

Use para erros, dúvidas, sugestões, pedidos de privacidade e propostas de melhoria. O repositório também concentra o código e o histórico técnico do projeto.

Como escrever um relato útil

  • Descreva o que você esperava e o que aconteceu.
  • Informe o aparelho, o navegador e a versão do aplicativo, se souber.
  • Inclua os passos para reproduzir o problema, sem dados pessoais.
  • Se for um erro visual, uma captura de tela ajuda — mas oculte nomes, conversas e chaves.
  • Não publique senhas, tokens do agente, chaves de API ou documentos pessoais.

Assuntos sensíveis

Para vulnerabilidades ou dados pessoais, siga as orientações da página de Segurança: abra um issue mínimo, sem segredos, e peça um canal privado antes de enviar detalhes. Pedidos de privacidade também podem ser registrados pelo GitHub Issues, indicando apenas o necessário.

O que não está disponível

  • Não há atendimento por telefone nem caixa de e-mail de suporte publicada nesta versão.
  • Não há SLA, plantão 24/7 ou programa de recompensas por vulnerabilidades.
  • O projeto é independente e não possui empresa, CNPJ ou sede declarados.

Antes de abrir um issue

Consulte a Política de Privacidade e os Termos de Uso. Muitas dúvidas sobre onde os dados ficam, como apagar o histórico e como o acesso remoto funciona já estão respondidas nessas páginas.
